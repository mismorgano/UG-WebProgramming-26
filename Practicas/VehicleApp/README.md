# Vehicle Control APP

This project contains a web app for creating, deleting, editing and visualize vehicles.
It's composed of two main parts the backend written in [C#](https://learn.microsoft.com/en-us/dotnet/csharp/) using the [ASP.NET Core](https://dotnet.microsoft.com/en-us/apps/aspnet) framework.
It's a [controller-based web API](https://learn.microsoft.com/en-us/aspnet/core/tutorials/first-web-api?view=aspnetcore-10.0&tabs=visual-studio), using dotnet 10.
The frontend is simply an [angular](https://angular.dev/) (v22) project that consumes the API.
